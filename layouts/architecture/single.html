3 — Trade Advisor Agent

The advisor runs as a single POST /advisor call on cloud-predict-core. It assembles context in parallel, then asks Claude Opus to make a structured BUY/SELL/HOLD decision.

1 Inputs
city, target_date, threshold (°C), account_balance_usdc
2 Parallel data fetch (Go goroutines)
  • Ensemble member_temps — ECMWF, GFS, ICON, GEM, AIFS
  • All forecasts for city/date (all 10 sources)
  • Polymarket latest snapshot (price, spread, volume)
  • Historical accuracy (MAE/RMSE/Bias per source × lead)
3 Ensemble aggregation
Concatenates all member_temps across sources (~150–200 total). Computes:
P(tmax ≥ threshold) = fraction of members above the market threshold.
Builds 1°C bracket histogram. Computes P10/P50/P90, mean, skewness.
4 Claude Opus decision
Sends structured text prompt with all data to Claude Opus 4.7 (extended thinking enabled). Gets back JSON: action, confidence, size_usdc, limit_price, rationale.
Decision Rules Claude is given
ConditionAction
ensemble_prob > market_YES + 0.05BUY YES shares
ensemble_prob < market_YES − 0.05SELL (buy NO shares)
|edge| < 0.05HOLD
No snapshot for this thresholdNO_MARKET
Position sizing (max 10% of account, up to 15% on strong edge):
Size down when: spread > 0.03, lead_days > 5, <100 members, poor model accuracy.
Size up when: edge > 0.15, lead ≤ 2 days, high ensemble agreement, good liquidity.

Limit price: BUY at best_ask + 0.01–0.02. SELL at (1 − YES) + 0.01.

4 — MCP Server (cloud-predict-mcp)

A stdio-based Model Context Protocol server that wraps the cloud-predict-core API. Any Claude agent (desktop app, Claude Code, custom agent) can connect to it and use these tools to do its own market analysis without going through the frontend.

list_cities
All tracked cities with slug, timezone, active status. Use to discover what markets exist.
get_polymarket_prices
Latest YES/NO price snapshots for a city + date. Returns best_bid, best_ask, spread, volume, liquidity per temperature bracket.
get_price_history
Polymarket price evolution over a date range. Useful for backtesting or spotting market drift patterns.
get_forecasts
Weather model forecasts for a city. Ensemble sources return full member_temps[]. Filterable by source, forecast_date, lead_days.
get_model_accuracy
Historical MAE / RMSE / bias per source × city × lead-day. Use to weight model confidence before deciding on edge.
get_data_coverage
Row counts, date ranges, and % of rows with resolved actuals per source/city. Sanity-check data quality before trading.
get_ensemble_probability — key decision tool
Aggregates member_temps from all 5 ensemble models (ECMWF, GFS, ICON, GEM, AIFS) into a single temperature probability distribution for a city/date. Builds a 1°C bracket histogram. Returns P10/P50/P90, mean, and P(tmax ≥ X) for any threshold. Compare against Polymarket YES prices to find mispricing edge directly from an agent without writing custom code.
Connect to it: add to ~/.claude/claude_desktop_config.json or Claude Code MCP settings:
CLOUDPREDICT_API_URL=https://your-tunnel.trycloudflare.com CLOUDPREDICT_API_TOKEN=... npx cloud-predict-mcp

6 — Repositories

cloud-predict-core
Go REST API (V2). Migrations, ingest workers, advisor handler, MCP-compatible endpoints. Runs on Proxmox.

TypeScript MCP server. 7 tools wrapping the core API. Connect via Claude desktop or Claude Code.
cloud-predict-trader
Go trading bot. Claude agent loop → EIP-712 signed orders → Polymarket CLOB API. Paper-trade mode active.
cloud-predict-ml
Nightly PostgreSQL → BigQuery exporter. Feeds cold-path analytics and backtesting.

V1 Go API (Cloud Run + BigQuery). Legacy — still serving this frontend. Being phased out in favour of V2.
